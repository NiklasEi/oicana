## In-process PDF generation in milliseconds

Oicana is a tool for document templating. Write Layouts in Typst and render documents with inputs out of your Python code. Rendering happens in-process through a native extension, so there's no headless Chrome and no document data leaving your infrastructure.

The project does not only support Python, but also 6 other platforms/programming languages including the browser. The same templates work in all of them.

You can follow the getting started guide at https://oicana.com/docs/getting-started/1-setup/.
The code is source available at https://github.com/oicana/oicana.
