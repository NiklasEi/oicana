# Developing the Dart integration

The package wraps two backends behind one API, chosen by a conditional import in `lib/src/platform.dart`:

- **Native** (`lib/src/native`): bindings generated by [uniffi-dart](https://github.com/Uniffi-Dart/uniffi-dart) for `crates/oicana_uniffi`. `hook/build.dart` bundles the library for each target.
- **Web** (`lib/src/web`): `dart:js_interop` calls into the wasm-bindgen build of `integrations/browser/oicana_browser_wasm`.

## Native library

The `pubspec.yaml` of this package points the build hook at `target/release`, so build the library before running tests:

```bash
cargo build --release -p oicana_uniffi
dart test
```

The e2e tests need the packed e2e template:

```bash
cargo run --release -p oicana_cli -- pack e2e-tests/template -o e2e-tests/template -n '{template}-x.y.z.zip'
```

## Bindings

Regenerate the bindings after changing the API of `oicana_uniffi`, from the root of the repository. CI fails if they are out of date. Use the revision of uniffi-dart pinned in `.github/workflows/ci.yml`. The generator formats its output for the language version of the package, so run `dart pub get` first, or the formatting differs from CI:

```bash
cargo install --locked --git https://github.com/Uniffi-Dart/uniffi-dart --rev <revision> --features binary uniffi-dart
cargo build --release -p oicana_uniffi
(cd integrations/dart && dart pub get)
uniffi_bindgen_dart target/release/liboicana_uniffi.so --config integrations/dart/uniffi.toml --out-dir integrations/dart/lib/src/native
```

## WebAssembly

The publish workflow adds the WebAssembly build to `web/`. To try the web backend locally, build it into that directory:

```bash
wasm-pack build integrations/browser/oicana_browser_wasm --release --target web --no-pack --out-dir ../../dart/web
```

## Publishing

The native release workflow (`oicana_uniffi-v<version>` tag) tags the commit with `oicana_dart-v<version>` and dispatches the publish workflow on that tag. The publish workflow bundles the `SHA256SUMS` of the native release as `hook/SHA256SUMS`, so the hook verifies downloads against checksums shipped with the package.

Automated publishing on pub.dev needs the tag pattern `oicana_dart-v{{version}}` with "workflow_dispatch" events enabled.
